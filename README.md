# Stride - Bootstrap 5 HTML template
A simple but clean Bootstrap 5 HTML template from https://templatedeck.com

## Pagamentos e faturas

A página `pagamento.html` está preparada para um Stripe Payment Link, mantendo a avaliação inicial gratuita. A cobrança pública fica desabilitada até configurar um link de produção em `js/payment-config.js`.

Consulte o [plano e guia de integração Stripe](_tools/stripe/README.md) para ativação, Invoicing, uso administrativo das chaves de API e testes.
